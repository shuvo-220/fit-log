FitLog – Workout Management App
FitLog is a modern workout management web application where users can browse exercises, view workout details, save their favorite exercises, and create a personalized workout plan.The application provides a simple and responsive interface to help users organize their daily workouts efficiently.

Technology used:
Next.js – React framework for building the application
React.js – Component-based UI development
JavaScript – Application logic and functionality
Tailwind CSS – Responsive and modern UI styling
DaisyUI – Pre-built UI components
React Icons – Icons throughout the application
Context API – Global state management for workout plans and saved exercises
Next.js Dynamic Routing – Exercise details pages based on dynamic IDs
REST API – Fetching workout/exercise data

Key Features
1. Browse Workouts

Users can browse different workout exercises and explore available workout information such as exercise name, equipment, duration, calories, rating, and muscle groups.

2. Create Today's Workout Plan

Users can add exercises to their Today's Plan and manage their daily workout routine.

The application also keeps track of:

Total exercises
Total workout minutes
Total calories
3. Save Favorite Exercises

Users can save exercises they are interested in and access them later from the Saved section.

They can also remove saved exercises whenever they want.

4. Workout Details & Dynamic Routing

Each exercise has its own details page using Next.js Dynamic Routing.

Users can view detailed information about a particular workout through its unique ID.

5. Sort & Manage Workouts

Users can sort their workout list based on:

Duration
Calories
Rating

They can also mark exercises as completed or remove them from their workout plan.
